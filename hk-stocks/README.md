# 港股学习计划（教练：Claude）

> 平台：长桥证券（Longbridge）｜学员水平：新手｜当前持仓：600 股「两倍做多恒生科技」杠杆产品

## 学习规则

1. **一课一课来**：每节课末尾有「课后小测」，你回答后由我批改，**正确率 ≥ 80% 才进入下一课**。
2. **每日复盘**：每个交易日收盘（16:10 港股收市竞价结束）后，按 [`reviews/daily-review-template.md`](reviews/daily-review-template.md) 写一份复盘，发给我点评。
3. **每周回顾**：每周末做一次「周测」，随机抽前面学过的知识点，防止学了就忘。
4. **先懂再买**：学完第一阶段之前，**不再新开任何仓位**，尤其不加仓杠杆产品。
5. 我是教练不是投资顾问：我教你方法和原理，**不替你做买卖决定**，也不预测涨跌。
