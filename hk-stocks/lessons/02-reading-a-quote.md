# L2 看懂一只股票的报价页

> 实操课：一边看讲义，一边在长桥里打开 **07226** 和 **00700 腾讯** 的详情页对照。

## 1. 价格类
| 字段 | 含义 | 注意 |
|---|---|---|
| 现价 / 最新价 | 最近一笔成交的价格 | 不是你一定能买到/卖到的价格（那要看盘口，L3 讲） |
| 昨收 | 上一个交易日的收盘价 | 今天的涨跌幅都以它为基准 |
| 今开 | 今天开盘竞价产生的价格 | 和昨收的差叫「跳空」（高开/低开） |
| 最高 / 最低 | 今天的最高/最低成交价 | 两者之差 ÷ 昨收 = **振幅**，衡量当天波动有多大 |
| 涨跌额 / 涨跌幅 | 现价 − 昨收；(现价 − 昨收) ÷ 昨收 | 07226 的涨跌幅应约等于恒科涨跌幅 × 2 |
| 52 周最高 / 最低 | 过去一年的价格区间 | 帮你判断现价处在高位还是低位 |

## 2. 成交类
| 字段 | 含义 | 注意 |
|---|---|---|
| 成交量 | 今天成交了多少**股** | 港股每手股数不同，跨股票比较成交量没意义 |
| 成交额 | 今天成交了多少**钱**（港元） | **比成交量更有用**：成交额越大，流动性越好，越容易按合理价格买卖 |
| 换手率 | 成交量 ÷ 流通股数 | 越高说明交投越活跃 |
| 均价 | 当天成交额 ÷ 成交量 | 现价高于均价，说明今天买入的人平均是赚钱的 |

## 3. 公司 / 产品类
| 字段 | 含义 |
|---|---|
| 总市值 | 股价 × 总股数，公司在市场上「值多少钱」 |
| 市盈率 PE、市净率 PB、股息率 | 估值指标，L12 详讲（杠杆产品没有这些） |
| 每手股数 | 买卖的最小单位，07226 是 100 股/手 |
| 一手金额 | 现价 × 每手股数，就是你最少要花多少钱 |

## 4. 杠杆产品特有：资产净值（NAV）与溢价/折价
- **NAV（资产净值）**：产品每股实际「值」多少，由发行商每天公布；盘中有「预估净值（IIV）」。
- 正常情况下，**市价 ≈ 净值**，由庄家（流通量提供者）维持。
- **市价 > 净值 = 溢价**（买贵了），**市价 < 净值 = 折价**。
- 杠杆产品的净值可在发行商（南方东英）官网查看。

## 5. 价位（tick size）：最小价格变动
港股价格不能随便报，必须符合价位表，例如：
| 股价区间（港元） | 每跳 |
|---|---|
| 0.25 – 0.50 | 0.005 |
| 0.50 – 10.00 | 0.010 |
| 10.00 – 20.00 | 0.020 |
| 20.00 – 100.00 | 0.050 |
| 100.00 – 200.00 | 0.100 |
| 200.00 – 500.00 | 0.200 |

> 例：07226 在 3–4 港元附近，每跳 0.01；腾讯在 200–500 区间时每跳 0.2。下限价单时价格不符合价位，系统会拒绝。（价位表以港交所最新规定为准，这里只列常见区间。）

## 课后小测（L2）
1. 07226 昨收 3.80，现价 3.99，涨跌幅是多少？
2. 为什么比较两只港股的活跃度时，看「成交额」比看「成交量」更靠谱？
3. 某股今天最高 10.50，最低 9.90，昨收 10.00，振幅是多少？
4. 在长桥打开 07226：现在一手要花多少钱？今天的成交额大约多少？
5. 07226 的市价 3.90，发行商公布的净值 3.85，这是溢价还是折价？你此时买入是吃亏还是占便宜？
6. 腾讯现价若为 400 港元，你想挂 400.10 买入，能下单成功吗？为什么？
